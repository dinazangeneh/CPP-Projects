# Number Analyzer 🔢

A C++ program that analyzes a 10-digit number and classifies its two-digit parts.

## Features

- Splitting a 10-digit number into smaller parts
- Detecting:
  - Prime numbers
  - Perfect numbers
  - Fibonacci numbers
  - Even and odd numbers
- Saving results into a text file

## Concepts Used

- C++
- Functions
- Arrays
- File Handling
- Number Theory Algorithms

## Purpose

This project was created to practice C++ functions, arrays, file handling, and algorithmic problem solving.
