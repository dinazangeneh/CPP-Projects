# Number Guessing Game 🎮

A C++ console game where the player tries to guess a randomly generated number.

## Features

- Random number generation
- Interactive guessing system
- Hint system (higher/lower)
- Player scoring
- Performance evaluation
- Comparison with global average score

## Concepts Used

- C++
- Loops
- Functions
- Random Number Generation
- User Input Handling
- Basic Game Logic

## Purpose

This project was created to practice C++ programming concepts, game loops, and designing interactive console applications.
