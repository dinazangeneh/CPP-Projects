# Bank Vault Security System 🔐

A C++ console-based security system simulation using matrix processing and password validation.

## Features

- 4-digit password validation
- Prime number security check
- 6x6 binary access matrix processing
- Row security analysis
- Matrix transformation
- Finding the column with maximum access level

## Concepts Used

- C++
- 2D Vectors
- Functions
- Loops and Conditions
- Matrix Operations
- Algorithm Design

## Purpose

This project was created to practice problem solving, matrix manipulation, and designing a simple security system simulation.
