# Bank Vault Security System 🔐

A C++ console application that simulates a simple bank vault security system using password validation and matrix processing.

## Features

- Validate a 4-digit numeric password
- Check whether the sum of password digits is a prime number
- Read and process a 6×6 binary access matrix
- Automatically invert rows with an odd number of active cells
- Analyze each row and assign a security level
- Identify the first column with the highest sum
- Display the final processed matrix

## Security Levels

- **Code A** – High Security (more than 4 active cells)
- **Code B** – Normal Security (2 to 4 active cells)
- **Code C** – Low Security (less than 2 active cells)
